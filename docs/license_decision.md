# Code license decision

The fellow reported that Benjamin has not specified a code license. No LICENSE
file has been added, and the repository must not be described as MIT-licensed.
This open decision does not block local development, testing, or validation.

A proposed option for the eventual decision is the standard
[MIT License](https://opensource.org/license/mit), which permits reuse and
modification subject to retaining its copyright and permission notice. This is
an option for review, not an enacted license or a claim about ChiEAC ownership.
Use the agreed copyright holder and exact standard text when the choice is made.
The separate fellow/ChiEAC ownership terms are not inferred from this proposal.
