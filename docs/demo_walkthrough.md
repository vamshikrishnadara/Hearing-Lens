# Four-minute demonstration

Use a small fictional file and the local dashboard. Prepare the models and open
the app beforehand. A recorded demonstration should show the actual result;
trim waiting time only if the edit is identified. Do not imply that a local run
measures online speed.

| Time | Screen | Suggested explanation |
| --- | --- | --- |
| 0:00-0:30 | Upload page | Hearing Lens summarizes community-feedback exports. It groups comments, estimates tone and identifies questions for follow-up. Use fictional data for this preview. The online demo has a small-file limit; larger files run locally. |
| 0:30-1:00 | Mapping and validation | Select the comment column and any genuine optional date, ID or subgroup fields. Validate and check the usable count and redacted preview. Cleaning may remove blanks and repeated IDs. |
| 1:00-1:45 | Themes | Run analysis once. These are statistical groups, not a human coding scheme. Counts include ungrouped comments in the denominator. Inspect supporting quotes in context and check for identifiers. |
| 1:45-2:20 | Sentiment and Timeline | Labels estimate expressed tone, not agreement or a person's characteristics. The tables provide the chart numbers. Missing dates cannot support a time trend. |
| 2:20-2:50 | Representation and Questions | Group comparisons need suitable supplied references. Small categories are hidden. Questions are suggested priorities; a possible response match is not proof of a complete answer. |
| 2:50-3:30 | Downloads and brief | Download the labeled CSV or prepare Word and PDF briefs. The brief shows leading themes and explicitly accounts for the remainder. Check the output before sharing. |
| 3:30-4:00 | Methodology and limitations | Review the models, measured agreement and limitations. Use the local guide for complete larger files. Automated output supports discussion and needs human interpretation. |

For an XLSX demonstration, use a workbook with a clearly named feedback sheet
and show the sheet selector before mapping. Use fictional input without
identifying information. An example recording does not
replace independent usability or accuracy checks.
